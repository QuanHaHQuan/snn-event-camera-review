# Survey Core Reading Plan

Strictly serves the survey **Spiking Neural Networks for Event Cameras**. Event representation and SNN computation are parallel foundations; the Core focuses on their explicit intersection and indispensable supporting evidence.

Current core: **26 papers**.

Composition: **15 anchor + 2 included + 9 selected background**.
This newest-first inventory is not a prescribed reading sequence. Read by method cluster using `03-review-draft/outline.md` and its checkpoints.
